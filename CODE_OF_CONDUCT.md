# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Everyone who participates — in issues, pull requests,
discussions or any other project space — is expected to follow it.

In short: be welcoming and considerate, assume good intent, critique ideas
rather than people, and accept that maintainers have the final say on what is
merged. Harassment, personal attacks and discriminatory language are not
tolerated.

## Reporting

If you experience or witness unacceptable behaviour, report it to the
maintainer, [@mbehnasr](https://github.com/mbehnasr), using GitHub's
[report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
feature on the comment or issue concerned. Reports are handled confidentially.
Enforcement follows the
[Contributor Covenant enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
